
# 🎵 Music Playlist Manager

A Music Playlist Management System developed using C programming.

## Features
- Add songs to the playlist
- Display all songs
- Delete songs by name
- Doubly Linked List implementation
- Dynamic memory allocation

## Technologies Used
- C Programming
- Data Structures
- Pointers
- Doubly Linked Lists

## How to Run

Compile:
```bash
gcc playlist.c -o playlist
```

Run:
```bash
./playlist
```

## Concepts Learned
- Structures
- Pointers
- Linked Lists
- malloc() and free()
- Insertion and Deletion
